
# Sorting Algorithm Comparison Tool

## 📌 Project Overview

This console-based Java application compares the performance of three fundamental sorting algorithms( **Bubble Sort**, **Merge Sort**, and **Quick Sort** )using execution time and step count as metrics. It allows users to input or generate datasets and analyze algorithmic efficiency through a menu-driven interface.

This assignment was developed for **CIT300 Graded Practical Assignment 2**.


## Features

- Input numbers manually or generate random datasets
- Sort data using:
  - **Bubble Sort** (iterative)
  - **Merge Sort** (recursive)
  - **Quick Sort** (partition-based)
- Measure and display:
  - **Execution time** in nanoseconds
  - **Step count** for each algorithm
- Compare all algorithms in a formatted results table
- Menu-driven interface with **input validation**
